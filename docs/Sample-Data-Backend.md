## How to Test with Postman

### Step 1: Start the Backend
Ensure the backend is running with the `prod` profile to trigger Flyway migrations:
```bash
sudo ./mvnw clean package
sudo java -jar target/backend-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
```

### Step 2: GET Requests
You can verify the data by calling these endpoints:

| Feature | Endpoint | Expected Result |
| :--- | :--- | :--- |
| **Tasks** | `GET http://localhost:8080/api/tasks` | Array with 1 task object |
| **Animals** | `GET http://localhost:8080/api/animals` | Array with 1 animal object |
| **Notifications** | `GET http://localhost:8080/api/notifications` | Array with 1 notification object |

### Step 3: User Specific Data
If you want to filter by the test user ID (usually ID `1` if the DB was empty):
- `GET http://localhost:8080/api/tasks/user/1`
- `GET http://localhost:8080/api/animals/user/1`
- `GET http://localhost:8080/api/notifications/user/1`
