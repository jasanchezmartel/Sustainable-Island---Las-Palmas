# Backend Data Consumption Documentation

This document describes the management API for the Sustainable Island project. The backend provides endpoints to manage tasks, animals, and notifications.

## Technology Stack
- **Framework**: Spring Boot
- **Architecture**: MVC + Service Layer
- **Data Transfer**: JSON using DTOs (Data Transfer Objects)

## Data Models

### TaskDTO
Representación de una tarea enviada hacia/desde el frontend.

| Field     | Type    | Description                               |
| :-------- | :------ | :---------------------------------------- |
| `id`      | Long    | Unique identifier                         |
| `userId`  | Long    | ID of the user assigned to the task       |
| `name`    | String  | Name of the task                          |
| `waste`   | String  | Type of waste (e.g., Plastic, Paper)      |
| `amount`  | Integer | Quantity of waste collected               |
| `completed`| Boolean | Whether the task is finished              |

### AnimalDTO
Representación de un animal recolectado o rescatado.

| Field            | Type   | Description                         |
| :--------------- | :----- | :---------------------------------- |
| `id`             | Long   | Unique identifier                   |
| `userId`         | Long   | ID of the user who found the animal |
| `animalStatusId` | Long   | ID of the status of the animal      |
| `name`           | String | Name of the animal                  |
| `type`           | String | Species of the animal               |

### NotificationDTO
Representación de una notificación para el usuario.

| Field              | Type      | Description             |
| :----------------- | :-------- | :---------------------- |
| `id`               | Long      | Unique identifier       |
| `userId`           | Long      | ID of the receptor user |
| `message`          | String    | Notification content    |
| `dateNotification` | LocalDate | Date of the notification|

## Endpoints

### 📋 Tasks (`/api/tasks`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Get all tasks |
| `GET` | `/user/{userId}` | Get tasks for a specific user |
| `GET` | `/{id}` | Get task by specific ID |
| `POST` | `/` | Create a new task |
| `PUT` | `/{id}` | Update an existing task |
| `DELETE` | `/{id}` | Delete a task |

### 🐾 Animals (`/api/animals`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Get all animals |
| `GET` | `/user/{userId}` | Get animals found by a user |
| `GET` | `/{id}` | Get animal by specific ID |
| `POST` | `/` | Log a new animal |
| `PUT` | `/{id}` | Update animal details/status |
| `DELETE` | `/{id}` | Delete an animal record |

### 🔔 Notifications (`/api/notifications`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Get all notifications |
| `GET` | `/user/{userId}` | Get notifications for a user |
| `POST` | `/` | Send a new notification |
| `DELETE` | `/{id}` | Dismiss/Delete a notification |
